# ETH Sender

[English version](README.md)

Небольшая программа под Windows для рассылки ETH (BNB, AVAX) и ERC-20 токенов сразу с пачки кошельков. У каждого кошелька свой адрес получателя, так что ей удобно, например, выводить средства с кошельков на депозитные адреса бирж.

![Главное окно](docs/screenshots/running-ru.png)

Сети: Ethereum, Arbitrum, Optimism, Base, BSC, Avalanche, Robinhood Chain.

## Что умеет

- отправляет нативную монету, USDT/USDC (в том числе USDT0, USDC.e, USDbC и другие варианты, на Robinhood ещё USDG) или любой ERC-20 по адресу контракта
- сумма с кошелька: весь баланс, процент от баланса или случайная сумма из диапазона
- случайная пауза между кошельками, порядок как в файле или случайный, кнопка "Стоп"
- по каждой транзакции ждёт квитанцию, а для токенов ещё и ищет событие Transfer, и только после этого считает кошелёк готовым
- до 3 повторов при ошибках. Зависшая транзакция заменяется с тем же nonce, поэтому один и тот же перевод дважды не уйдёт
- перед стартом показывает балансы токена и нативной монеты по всем кошелькам
- интерфейс на русском и английском, тёмная и светлая тема

За один запуск одна сеть и один токен.

## Скачать

Возьмите zip на странице [Releases](https://github.com/vv-bobody/ETH_Sender/releases/latest), распакуйте куда угодно и запустите `ETH_Sender.exe`. Python не нужен.

Файл не подписан сертификатом, поэтому при первом запуске SmartScreen будет ругаться (Подробнее, затем Выполнить в любом случае). Некоторые антивирусы в принципе не любят сборки PyInstaller. SHA-256 архива указан на странице релиза, проверить можно так:

```
certutil -hashfile ETH_Sender-1.3.1-win64.zip SHA256
```

Если не хочется запускать чужой exe на машине с ключами, соберите сами, как это сделать написано ниже.

## Как пользоваться

При первом запуске программа создаёт рядом с exe файлы `settings.txt` и `wallets.txt`.

Кошельки вписываются в `wallets.txt`, по одному в строке:

```
# имя,приватный ключ,адрес получателя
Основной 1,0x<приватный ключ>,0x1111111111111111111111111111111111111111
# имя можно не писать
0x<приватный ключ>,0x2222222222222222222222222222222222222222
```

Дальше в окне:

1. Выберите сеть, токен, сумму и паузы и нажмите "Применить". Настройки сохранятся, программа проверит RPC и загрузит балансы.
2. Отметьте галочками кошельки, с которых отправлять.
3. Нажмите "Старт" и подтвердите.

![Окно подтверждения](docs/screenshots/confirm-ru.png)

По каждому кошельку в таблице видны статус, счётчик попыток и ссылка на транзакцию. Подробности пишутся в лог внизу.

Что ещё полезно знать:

- По умолчанию стоят публичные RPC, а они часто режут частоту запросов. Если часть балансов не загрузилась, нажмите ↻ в строке или "Повторить ошибки". Когда начинают сыпаться 429, программа и сама замедляет опрос. Свои адреса RPC можно вписать в панели настроек.
- Для старых мостовых токенов (USDC.e, USDbC, USDT.e) в окне подтверждения показывается предупреждение: биржи обычно зачисляют только родные USDC и USDT.
- Клик по адресу открывает его на DeBank, клик по хешу транзакции открывает эксплорер.
- Переключатели языка и темы находятся вверху панели настроек.
- Чтобы обновиться, распакуйте новую версию и скопируйте в неё свои `settings.txt` и `wallets.txt`.

![Светлая тема](docs/screenshots/ready-light-ru.png)

## Про ключи

`wallets.txt` это обычный текстовый файл с приватными ключами, ничего не шифруется, так что держите папку в надёжном месте. Ключи используются только локально, для подписи транзакций. Программа ходит только на RPC из настроек и больше никуда, а перед отправкой сверяет chain ID.

Отправленную транзакцию не отменить. Сначала попробуйте на небольшой сумме.

## Сборка из исходников

Нужны Windows 10/11 и Python 3.13.

```
build.bat
```

Получится `dist\ETH_Sender\ETH_Sender.exe` и ярлык на рабочем столе. Сборка идёт в отдельном окружении (`.venv-build`), зависимости ставятся только из `requirements.lock`, с проверкой хешей и только готовыми wheel. `settings.txt` и `wallets.txt` в `dist\ETH_Sender` при пересборке сохраняются, всё остальное в этой папке пропадает.

Чтобы обновить зависимости: обновите их в `.venv`, проверьте, потом запустите `tools\make_lock.py`. Он пересоздаст lock-файлы и откажется это делать, если в базе OSV для новых версий есть уязвимости.

## Для разработки

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt pytest
.venv\Scripts\python main.py
.venv\Scripts\python main.py --demo
.venv\Scripts\python -m pytest
```

`--demo` открывает окно с выдуманными данными и без доступа к сети, удобно для работы над интерфейсом (скриншоты здесь сделаны так же). `tools\check_networks.py` проверяет RPC по умолчанию, только чтение. `tools\render_ui.py` сохраняет снимки интерфейса в `design/`.

Тестам из `tests/test_local_chain.py` нужны `eth-tester` и `py-evm==0.12.1b1`, без них они пропускаются.

Тексты интерфейса в коде на английском, русский перевод лежит в `app/ru.py`. `tests/test_i18n.py` падает, если у какой-то строки нет перевода.

Комментарии вида "spec 5.6" в коде ссылаются на моё ТЗ к проекту. В репозитории его нет.

Сделано на Python, PySide6 (Qt 6), web3.py и PyInstaller.
